# qml/Widgets

## Purpose
通用UI组件库，包含按钮、输入框、布局、图像查看器等可复用组件。

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `IgnoreArea/` | 忽略区域组件 |
| `ImageViewer/` | 图像查看器组件 |
| `ResultLayout/` | 结果布局组件 |

## Key Components

| File | Description |
|------|-------------|
| `Button_.qml` | 按钮组件 |
| `IconButton.qml` | 图标按钮 |
| `IconTextButton.qml` | 图标文字按钮 |
| `CheckBox_.qml` | 复选框 |
| `FramelessWindow.qml` | 无边框窗口 |
| `Image_.qml` | 图像组件 |
| `DropArea_.qml` | 拖放区域 |
| `FileDialog_.qml` | 文件对话框 |
| `FilesTableView.qml` | 文件表格视图 |

## For AI Agents

### Working In This Directory
- 组件采用下划线后缀命名约定（`Button_.qml`）
- 组件支持样式定制和属性配置
- 复杂组件如图像查看器包含多个文件
