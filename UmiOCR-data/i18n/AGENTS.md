# i18n

## Purpose
国际化资源目录，包含Qt编译后的翻译文件(.qm)。

## Key Files

| File | Description |
|------|-------------|
| `*.qm` | Qt二进制翻译文件 |

## Supported Languages
- `en_US.qm` - 英语
- `ja_JP.qm` - 日语
- `pt.qm` - 葡萄牙语
- `ru_RU.qm` - 俄语
- `ta.qm` - 泰米尔语
- `zh_TW.qm` - 繁体中文

## For AI Agents

### Working In This Directory
- .qm 文件是Qt的二进制翻译格式，由 .ts 文件编译生成
- 翻译源文件在 `dev-tools/i18n/release/` 目录
- 翻译工作在 https://hosted.weblate.org/engage/umi-ocr/ 进行
